# Admin Management

- **Route:** `/admin-management`
- **Design:** [Figma section "Admin Management"](https://www.figma.com/design/q8WJ8duI2FR5mc7ESAcUhi/Talent-cona-Admin-Portal--Copy-?node-id=293-18341)
- **Status:** Migrated to the Next.js App Router; the sidebar route is enabled.

The page supports pending invitations, active admins, creating invitations, and editing
admin roles/program assignments. Its records are held in client-side state for this
demo and are not persisted to a backend.
